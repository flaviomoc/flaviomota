# Flávio Mota — Ecologia e Conservação

Website e portfólio acadêmico pessoal de **Flávio Mota**, pesquisador e ecólogo especializado em macroecologia, conservação da biodiversidade, mudanças climáticas, análise espacial e modelagem de nicho ecológico.

---

## 🌿 Sobre o Projeto

Este repositório contém a página web pessoal estática, desenvolvida em HTML5, CSS moderno e JavaScript vanilla, sem dependências de frameworks pesados, garantindo carregamento rápido, excelente legibilidade tipográfica e compatibilidade total com dispositivos móveis e navegadores modernos.

### Seções Incluídas:
- **Sobre**: Resumo da linha de pesquisa, atuação editorial e métricas científicas (artigos, citações no Web of Science, pacotes).
- **Pesquisa**: Principais linhas de investigação científica.
- **Trajetória Acadêmica**: Linha do tempo com formação e experiências de pesquisa e docência (ICMBio, UNIMONTES, UESC, UFMG).
- **Publicações Selecionadas**: Artigos publicados em periódicos como *Diversity and Distributions*, *Journal of Applied Entomology*, *Scientific Data (Nature)* e *Ecography*, com links diretos via DOI.
- **Campo e Divulgação**: Galeria contínua de fotos de campo, geoprocessamento e eventos acadêmicos.
- **Visualizações Científicas**: Carrossel com mapas temáticos, modelagens e fluxogramas metodológicos.
- **Ferramentas e Softwares**: Pacotes abertos em R para análise espacial e diversidade (`divraster`, `phyloraster`, `SESraster`).
- **Contato**: Formulário e canais de comunicação direta, além de links para ORCID, ResearchGate, GitHub, LinkedIn, Lattes e Instagram.

## 🚀 Como Executar Localmente

### Opção 1: Abrir diretamente no navegador
Por ser uma aplicação web estática pura, você pode simplesmente abrir o arquivo `index.html` em qualquer navegador:
```bash
# No Linux / macOS
open index.html

# Ou no Windows
start index.html
```

### Opção 2: Servidor local Node.js
Se preferir rodar com o servidor Node incluído:
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar o servidor
npm start
# O site estará disponível em http://localhost:3000
```

## 🌐 Publicação no GitHub Pages

Para publicar este site gratuitamente pelo **GitHub Pages**:

1. Faça o commit e envie este repositório para o seu GitHub (ex.: `github.com/flaviomoc/flaviomoc.github.io` ou no repositório de sua escolha).
2. No seu repositório no GitHub, acesse **Settings** > **Pages**.
3. Na seção **Build and deployment**:
   - **Source**: selecione `Deploy from a branch`.
   - **Branch**: selecione `main` (ou `master`) e a pasta `/ (root)`.
4. Clique em **Save**.
5. Em alguns instantes, o site estará no ar no seu endereço `https://flaviomoc.github.io/`!
